Hooks 系统：生命周期事件

Hooks（钩子）是 Claude Code 的自动化引擎，让你能在特定事件发生时自动执行脚本，实现工作流自动化。

1. 什么是 Hooks

1.1 定义

Hooks 是 事件驱动的自动化机制，允许你在 Claude Code 的特定生命周期事件发生时执行自定义脚本或命令。

1.2 核心价值

场景 无 Hooks 有 Hooks
代码格式化 每次手动运行 prettier 文件保存后自动格式化
安全检查 容易遗忘 每次修改自动检查
上下文注入 手动复制粘贴 会话启动自动注入
权限控制 Claude 可能执行危险操作 自动拦截并确认

1.3 工作原理

sequenceDiagram
    participant U as 用户/Claude
    participant CC as Claude Code
    participant HM as Hook Manager
    participant S as Hook Script
    
    U->>CC: 触发动作
    CC->>HM: 发送事件
    HM->>HM: 匹配 Hooks
    
    alt 匹配成功
        HM->>S: 执行脚本 (stdin: 事件数据)
        S-->>HM: 返回结果 (stdout + exit code)
        HM->>HM: 处理返回值
        
        alt exit code = 0
            HM-->>CC: 继续执行
        else exit code = 2
            HM-->>CC: 阻止执行
        else exit code = 其他
            HM-->>CC: 错误处理
        end
    else 无匹配
        HM-->>CC: 继续执行
    end

2.2 事件详解

SessionStart - 会话启动

触发时机：会话启动、恢复、清除、压缩时

典型用途：

  • 注入项目上下文（Git 状态、TODO 列表）
  • 加载 Skills 元数据
  • 设置环境变量

事件数据：

UserPromptSubmit - 用户提交提示词

触发时机：用户发送消息后，Claude 处理前

典型用途：

  • 追加动态上下文
  • 请求转换/预处理
  • 日志记录

事件数据：

PreToolUse - 工具调用前

触发时机：Claude 决定调用工具，但尚未执行

典型用途：

  • 拦截危险操作
  • 验证参数
  • 修改工具参数

事件数据：

PermissionRequest - 权限请求

触发时机：工具需要用户授权前

典型用途：

  • 自动批准安全操作
  • 自动拒绝危险操作
  • 自定义权限逻辑

事件数据：

PostToolUse - 工具调用后

触发时机：工具成功执行后

典型用途：

  • 运行格式化工具
  • 运行 Linter
  • 触发构建

事件数据：

PostToolUseFailure - 工具调用失败

触发时机：工具执行失败后

典型用途：

  • 错误日志记录
  • 错误通知
  • 自动重试逻辑

事件数据：

SubagentStart / SubagentStop - 子代理生命周期

触发时机：子代理启动/停止时

典型用途：

  • 监控子代理
  • 资源管理
  • 日志记录

Notification - 通知

触发时机：系统发送通知时

典型用途：

  • 自定义通知处理
  • 外部系统集成

Stop - 停止

触发时机：Claude 完成响应时

典型用途：

  • 清理临时文件
  • 保存状态
  • 发送通知

PreCompact - 压缩前

触发时机：执行 /compact 前

典型用途：

  • 保存重要上下文
  • 自定义摘要逻辑

SessionEnd - 会话结束

触发时机：会话完全结束时

典型用途：

  • 清理资源
  • 保存日志
  • 发送报告

5. Hook 脚本编写

5.1 输入输出规范

Hook 脚本通过 stdin 接收事件数据，通过 stdout 返回结果，通过 exit code 控制流程。

graph LR
    CC[Claude Code] -->|stdin: JSON| Script[Hook Script]
    Script -->|stdout: 结果| CC
    Script -->|exit code| CC

5.2 Exit Code 含义

Exit Code 含义 行为
0 成功，继续执行 stdout 内容追加到上下文
2 阻止操作 取消当前工具调用
其他 错误 记录错误，继续执行

5.3 环境变量

Hook 脚本可以访问以下环境变量：

变量 说明
CLAUDE_PLUGIN_ROOT .claude 目录的绝对路径
CLAUDE_FILE_PATH 当前操作的文件路径（如适用）
CLAUDE_TOOL_NAME 当前工具名称
CLAUDE_SESSION_ID 当前会话 ID

9. 常见问题

Q: Hook 脚本没有执行怎么办？

A: 检查以下几点：

  1. 脚本是否有执行权限（chmod +x script.sh）
  2. hooks.json 格式是否正确（使用 JSON 验证器）
  3. matcher 是否匹配目标事件
  4. 查看 Claude Code 日志

A:

Q: Hook 脚本可以访问网络吗？

A: 是的，Hook 脚本在你的本地环境执行，拥有你的用户权限，可以访问网络。

Q: 如何在 Windows 上使用 Hooks？

A:

  1. 使用 .cmd 或 .bat 脚本
  2. 或者安装 WSL/Git Bash 使用 Shell 脚本
  3. 或者使用跨平台脚本语言（Python、Node.js）

Q: Hook 执行超时怎么处理？

A: 默认没有超时限制，建议：

  1. 避免在 Hook 中执行耗时操作
  2. 使用后台执行（&）处理长时间任务
  3. 在脚本中设置自己的超时

Q: 多个 Hook 的执行顺序是什么？

A:

  1. 同一事件的多个配置按 JSON 数组顺序执行
  2. 同一配置的多个 hooks 按数组顺序执行
  3. 如果某个 Hook 返回 exit code 2，后续 Hook 不会执行
