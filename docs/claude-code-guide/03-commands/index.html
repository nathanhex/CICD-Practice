Commands 系统：斜杠命令

Commands（命令）是 Claude Code 的快捷入口，通过简单的 /command 语法快速触发特定功能。

1. 什么是 Commands

1.1 定义

Commands 是以 / 开头的快捷指令，类似于 Slack 或 Discord 的斜杠命令。它们提供了一种快速、可预测的方式来触发 Claude Code 的特定功能。

1.2 命令类型

graph TB
    Commands[Commands 命令系统]
    Commands --> Built[内置命令]
    Commands --> Custom[自定义命令]
    
    Built --> Config[/config - 配置]
    Built --> Init[/init - 初始化]
    Built --> Help[/help - 帮助]
    Built --> Clear[/clear - 清除]
    
    Custom --> Legacy[.claude/commands/*.md
传统方式]
    Custom --> Skills[.claude/skills/*/SKILL.md
技能方式]

1.3 命令执行流程

sequenceDiagram
    participant U as 用户
    participant CC as Claude Code
    participant CM as Command Manager
    participant S as Skills/Commands
    
    U->>CC: /review src/file.java
    CC->>CM: 解析命令
    CM->>CM: 查找命令定义
    
    alt 内置命令
        CM->>CC: 执行内置逻辑
    else 自定义命令
        CM->>S: 加载命令/技能文件
        S-->>CM: 返回指令内容
        CM->>CC: 注入指令到上下文
    end
    
    CC->>U: 执行结果

2. 内置命令

Claude Code 提供了一系列内置命令：

2.1 核心命令列表

命令 功能 示例
/help 显示帮助信息 /help
/config 打开配置界面 /config
/init 初始化 CLAUDE.md /init
/clear 清除对话历史 /clear
/compact 压缩上下文 /compact
/cost 显示 Token 使用情况 /cost
/doctor 诊断问题 /doctor
/login 登录账户 /login
/logout 登出账户 /logout
/model 切换模型 /model sonnet
/permissions 管理权限 /permissions
/status 显示状态 /status
/memory 管理记忆 /memory
/review 代码审查 /review file.js
/terminal-setup 终端设置 /terminal-setup

2.2 命令详解

/init - 初始化项目

自动分析项目结构，生成 CLAUDE.md 配置文件：

  • 检测技术栈（语言、框架）
  • 识别构建工具
  • 发现目录结构
  • 生成基础规则

/config - 配置管理

打开配置界面，可以管理：

  • API 密钥
  • 模型选择
  • 权限设置
  • MCP 服务器

/compact - 上下文压缩

当对话变长、Token 使用过多时：

  • 总结历史对话
  • 保留关键信息
  • 释放上下文空间

/model - 模型切换

特性 commands/*.md skills/*/SKILL.md
支持文件 ❌ 单文件 ✅ 目录+多文件
Frontmatter ❌ 不支持 ✅ 支持
自动匹配 ❌ 仅手动触发 ✅ 支持自动匹配
工具限制 ❌ 不支持 ✅ 支持
推荐程度 简单场景 复杂场景

建议：新项目使用 Skills 方式，旧的 commands 文件保持兼容。

4.2 工作原理

  1. 命令解析：用户输入 /review
  2. 查找实现：
    • 先查找 .claude/commands/review.md
    • 再查找 .claude/skills/review/SKILL.md
    • 如果都存在，Skills 优先
  3. 加载执行：加载找到的文件内容作为指令

8. 常见问题

Q: 命令没有被识别怎么办？

A: 检查以下几点：

  1. 文件位置是否正确（.claude/commands/ 或 .claude/skills/）
  2. 文件名是否与命令名匹配
  3. 对于 Skills，检查 name 字段
  4. 使用 /help 查看可用命令列表

Q: 如何查看所有可用命令？

A:

Q: 命令参数如何解析？

A: 参数以空格分隔，按顺序赋值给 $1, $2, $3…，完整字符串存储在 $ARGUMENTS。

Q: 可以创建带子命令的命令吗？

A: 不直接支持，但可以在命令内部解析：

Q: 如何禁用某个内置命令？

A: 目前不支持禁用内置命令，但可以创建同名的自定义命令来覆盖（不推荐）。

Q: 命令可以异步执行吗？

A: 命令本身是同步的，但可以：

  1. 在命令中使用 Task 工具创建后台代理
  2. 使用 Shell 执行后台任务（&）
